# Rock, Paper, Scissors (Python)

A command-line Rock, Paper, Scissors game built in Python. This project demonstrates core programming fundamentals, including `while` loops, conditional logic, user input validation, and modular code using functions.

## Features
* **Interactive Gameplay:** Play continuous rounds against the computer until you choose to quit.
* **Score Tracking:** Keeps track of wins, losses, and ties across rounds.
* **Input Validation:** Handles invalid entries and case sensitivity gracefully without crashing.
* **Modular Design:** Separates game logic (getting choices, determining a winner, displaying scores) into clean, reusable functions.

## Prerequisites
* **Python 3.x** installed on your system.
* No external libraries required (uses Python's built-in `random` module).

## Installation & Setup
1. Clone the repository or download the project files:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the project directory:
   ```bash
   cd rock-paper-scissors
   ```
